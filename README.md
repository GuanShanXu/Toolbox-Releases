## 功能更新

- 常用工具栏操作改为图标，鼠标悬停或键盘聚焦显示名称提示。
- 统一文本和数字输入框样式，去除重复边框；日志操作栏改为紧凑图标。
- 修复工具栏首次打开、调整窗口及跨屏缩放时挤成一列、参数被裁切的问题。
- 优化相机采集页布局和操作状态；图像发送目标改为菜单选择。
