# 调试盒子

Windows x64 调试工具盒，包含网络、硬件、文件、办公、程序开发和机器视觉工具，以及截图、贴图、录屏。

此仓库只用于公开发行安装包、使用说明和签名更新清单。源码保留在作者的私有仓库。

- [Gitee 发行页面](https://gitee.com/infinite-possible/toolbox-releases/releases)
- [GitHub 备用发行页面](https://github.com/GuanShanXu/Toolbox-Releases/releases)

安装包发布准备中。系统要求：Windows 10/11 x64、.NET Framework 4.8。
