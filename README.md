## 功能更新

- 界面与交互：90 项功能整理为 39 个入口，支持科技蓝、浅色和深色主题；优化按钮分组、右键菜单、快捷键及不同 DPI 下的布局。
- 办公工具：新增表格对比与清洗、PDF 页面整理与对比、Office 转 PDF、Word 模板批量生成、文本模板、剪贴板历史、条码标签和离线资料库。
- 机器视觉：新增缺陷测量、图像处理流程、海康实时采集与调焦、平场校正、镜头畸变标定、NG 样品库、质量统计 / GR&R 和调试报告；增强良品 NG 配准、LCD 偏振打光及实拍对照。
- 电脑工具：新增快速搜索入口、文件查找与占用查询、局域网传输、窗口布局、演示辅助、增量备份、磁盘统计、网卡预设和开发环境对照。
- 工程与流程：新增工程计算、设备维护台账、自动化工作流、归档交付及 SSH / RDP / SFTP 连接管理。
- 截图录屏：新增上次区域复用、滚动截图、录屏剪辑和 GIF 导出；优化普通页面关闭后的资源释放。
- 修复优化：修复文字裁切、跨屏缩放错位、内容遮挡和 PDF 页面恢复失败；打光小窗口支持效果图与 3D 场景切换。
