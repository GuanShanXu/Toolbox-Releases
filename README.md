## 功能更新

- 文件速览：自动使用本机 Office 或 WPS，支持 DOC/DOCX、PPT/PPTX、XLS/XLSX 的版式、图片与表格预览。
- 大图预览：增加超高分辨率 PNG 的逐行缩略读取，改进 JPG、BMP、TIFF 等格式的解码，加入内存限制、取消和失败提示。
- 窗口交互：修复原生预览组件引起的重复标题栏，支持空格关闭；切换文件后释放预览资源。
