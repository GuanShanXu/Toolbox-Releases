## 功能更新

- 空格速览新增三维机械图纸、扫描点云和网格，可直接旋转、平移、缩放和复位。
- 支持 STEP、IGES、BREP、STL、PLY、PCD、OBJ、3MF、glTF、GLB、FBX、3DS 和 DAE。扫描点云保留 RGB，大点云显示采样数量。
- glTF 可读取配套 BIN，OBJ 可读取 MTL 材质颜色。SolidWorks、Parasolid 等原生图纸可使用本机 CAD 预览组件或模型缩略图。
