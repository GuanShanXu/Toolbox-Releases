## 功能更新

- 文件速览：兼容腾讯桌面整理，桌面选中文件后支持空格或 Ctrl+Space 预览，再按空格或 Esc 关闭。
- 交互优化：重命名和菜单操作不拦截空格；读取所选文件后恢复原剪贴板，空白处不误预览旧文件。
- 预览设置：新增腾讯桌面兼容开关，默认启用；关闭功能时取消尚未执行的读取请求。
