## 功能更新

- 录屏框选后显示悬浮菜单，系统声音和麦克风可独立开关，也可同时录制。
- 录屏开始后记住声音选择，图标显示开关状态，悬停或键盘聚焦可查看说明。
- 滚动截图移入截图选区工具栏，直接沿用当前区域，无需再次框选。
