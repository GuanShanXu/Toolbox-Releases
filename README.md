## 功能更新

- 更新提示：发现新版时，左上角“调试盒子”旁显示红色 NEW 标记，点击可查看更新说明。
- 文件速览：资源管理器或桌面选中文件后按空格预览，再按空格或 Esc 关闭；支持文件切换、文档翻页、图片缩放和窗口固定。
- 后台与设置：文件速览在软件后台继续可用，左下角管理菜单和托盘可设置开关及快捷键；关闭预览时释放内容资源。
